Coloca aquí tu PDF real con el nombre `programa.pdf`.

Desde la raíz del proyecto ejecuta:

```bash
python document_processor.py data/programa.pdf
```

Antes, completa `NVIDIA_API_KEY` en `.env`. No se ha colocado un programa ficticio
en esta ruta. Los PDF sintéticos de prueba se generan en `output/` o en carpetas
temporales.
